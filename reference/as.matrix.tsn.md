# Coerce a TSN result to a weighted adjacency matrix

Coerce a TSN result to a weighted adjacency matrix

## Usage

``` r
# S3 method for class 'tsn'
as.matrix(x, rownames.force = NA, ...)
```

## Arguments

- x:

  A `tsn` result.

- rownames.force:

  Ignored.

- ...:

  Ignored.

## Value

A named numeric matrix.
