# Daily Step Counts

An example longitudinal data set containing daily step counts for 151
individuals from 2019-04-16 through 2020-03-01. Each `(id, day)` pair is
unique. There are 3,046 missing step counts.

## Usage

``` r
steps
```

## Format

A data frame with 34,089 rows and three variables:

- id:

  Integer individual identifier.

- day:

  Calendar date stored as `YYYY-MM-DD` text.

- steps:

  Daily step count, with some missing values.
