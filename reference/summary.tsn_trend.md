# Summarize a trend classification

Summarize a trend classification

## Usage

``` r
# S3 method for class 'tsn_trend'
summary(object, ...)
```

## Arguments

- object:

  A `tsn_trend` result.

- ...:

  Ignored.

## Value

A tidy data frame with one row per observed trend state, giving the
`count` and `proportion` of observations in that state.
